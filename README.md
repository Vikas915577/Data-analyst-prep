# Vikas Career

Personal mobile-first Data Analyst learning and job application app.

Built around Vikas Sharma's resume profile:
- Data Analyst, 1+ year experience
- SQL, Power BI, Python, Birst BI, Advanced Excel
- Data validation, KPI reporting, ETL concepts
- Data warehousing, Star Schema, Fact & Dimension modeling
- Projects: Customer Sales Analytics, Credit Risk & Loan Analytics, Sales Performance, Power Consumption Analysis

## V1
- Home dashboard
- Resume-based skill map
- Learning lessons
- Interview practice quiz
- Job application tracker
- Profile and projects
- LocalStorage persistence

This is a static GitHub Pages app and needs no backend for V1.
